# 手工摆位说明 — 《让子弹飞》鸿门宴工程

工程：`工作区域文件夹\scenes\手工摆位_v1.mb`
机位表：`工作区域文件夹\camera_positions.csv`（71 行，Excel 可直接打开）

## 一、先说路径的事

**这个 .mb 不引用任何外部文件**：无 reference、无外部贴图（材质全是纯色 lambert），已实测 `cmds.file(q=True, reference=True)` 返回空。

所以换机器、挪文件夹、改盘符都不会丢东西。工程里所有节点名都是 ASCII，不会有中文名导致的路径问题。

---

## 二、组结构

顶层只有一个 `SCENE`，其余全在它下面：

```
SCENE
├── CHARS
│   ├── CHR_Ma              ← 马县长（移动这个）
│   │   └── Ma_..._arm       （骨架）
│   ├── CHR_Huang           ← 黄四郎
│   │   └── Huang_..._arm
│   ├── CHR_Shiye           ← 师爷
│   │   └── Shiye_..._arm
│   ├── Ma_..._mesh          ← 网格（别动，靠蒙皮跟随骨架）
│   ├── Huang_..._mesh
│   └── Shiye_..._mesh
├── CAMERAS                 ← 71 台，全部叫 SXXX_CAM1（S001_CAM1 … S071_CAM1）
├── GRP_SET                 ← 桌子 / 椅子 / 房子 / 地面 / 天空球
├── GRP_LIGHTS              ← 一盏弱环境光
└── HIDDEN_HELPERS          ← 蒙皮辅助网格（已隐藏，别动）
```

**为什么网格和人物组是平级的**：这些网格带着 ×100 缩放和蒙皮，改父级会再叠一次变换（我试过，模型直接被撑到几千单位）。所以它们留在 `CHARS` 下面不动，靠蒙皮跟随骨架。

**结论**：你只移动 `CHR_Ma` / `CHR_Huang` / `CHR_Shiye` 这三个组。实测：组移 20cm，网格整体跟着移 20cm，1:1，手的位置、蒙皮都不会散。

## 三、三个人物的位置

组的 Y 恒为 0，0 就是地面。**Y 不要改**，改了人会离地或陷进椅子。

| 人物 | 组名 | X | Y | Z | 朝向 rotateY | 头顶高度 |
|---|---|---|---|---|---|---|
| 马县长 | `CHR_Ma` | 0.00 | 0 | −102.00 | 0° | 90.9 |
| 黄四郎 | `CHR_Huang` | 88.33 | 0 | 51.00 | −120° | 102.5 |
| 师爷 | `CHR_Shiye` | −88.33 | 0 | 51.00 | 120° | 104.9 |

三人位于半径 102 的圆周上，每 120° 一个，都朝圆心。

## 四、怎么移动人物

1. 大纲里选 **整个组**（`CHR_Ma`），不要选里面的 arm 或 mesh
2. 按 `W` 切移动工具，改 **X / Z**
3. 改朝向：属性面板改 `rotateY`（0° = 面朝 +Z，也就是正对拍他的那台相机）

**手的姿态不会掉**——手是骨骼旋转摆出来的，不是约束，跟着人一起走。
**相机会不动**——相机是独立对象，人挪了要重新对准，见下一节。

## 五、相机重新对准（粘到脚本编辑器跑）

### 单台

```python
import maya.cmds as cmds

CAM  = 'S001_CAM1'   # 要调的相机
CHAR = 'CHR_Ma'      # 对准谁

t = cmds.xform(CHAR + '_Head', q=True, ws=True, t=True)
loc = cmds.spaceLocator()[0]
cmds.setAttr(loc + '.translate', t[0], t[1] - 2.0, t[2])
k = cmds.aimConstraint(loc, CAM, aimVector=(0, 0, -1), upVector=(0, 1, 0),
                       worldUpType='vector', worldUpVector=(0, 1, 0))
m = cmds.xform(CAM, q=True, ws=True, m=True)
cmds.delete(k)
cmds.delete(loc)
cmds.xform(CAM, ws=True, m=m)     # 朝向烘进 rotate，不留约束
```

### 71 台一次全对准

```python
import maya.cmds as cmds, json, os
ROOT = r"C:\Users\admin\Desktop\MayaProject\让子弹飞分镜测试\工作区域文件夹"
data = json.load(open(os.path.join(ROOT, "logs", "s20.json"), encoding="utf-8"))["data"]["cams"]
NAME = {"Ma": "CHR_Ma", "Huang": "CHR_Huang", "Shiye": "CHR_Shiye"}
for sid, c in data.items():
    cam, char = c["name"], NAME[c["subject"]]
    t = cmds.xform(char + "_Head", q=True, ws=True, t=True)
    loc = cmds.spaceLocator()[0]
    cmds.setAttr(loc + ".translate", t[0], t[1] - 2.0, t[2])
    k = cmds.aimConstraint(loc, cam, aimVector=(0, 0, -1), upVector=(0, 1, 0),
                           worldUpType="vector", worldUpVector=(0, 1, 0))
    m = cmds.xform(cam, q=True, ws=True, m=True)
    cmds.delete(k)
    cmds.delete(loc)
    cmds.xform(cam, ws=True, m=m)
```

1. `f8_render_all.py` — 按镜头连拍 → `frames_raw3/`，再重命名到 `frames_all3/`
