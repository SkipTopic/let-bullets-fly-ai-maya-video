## 渲染层 bug（WorkBuddy 30+ 轮排障记录在案，fix_s12~s32）

1. **首次渲染时 CAM_WIDE 已不存在**，`modelEditor(camera=...)` 静默失败 → 71 镜全部来自面板残留相机（0 次切镜）
2. **角色 mesh 自带 scale=100 + rotateX=-90**（FBX 单位遗产）与 arm 分离，bbox 顶 69 陷于桌面 75 之下
3. **修复后渲染层不显示角色**：mesh transform/顶点/visibility 数据全部正确（Maya API 可查），但视口/硬件渲染缓存与场景状态脱节——GPU 缓存固定、playblast 视口缓存无法更新、可见性反复开关中丢失
4. WorkBuddy 尝试：硬件渲染器、Arnold 真渲染、离屏渲染、顶点世界坐标直接验证、md5 对比极端姿势——确认"数据对、渲染骗人"
