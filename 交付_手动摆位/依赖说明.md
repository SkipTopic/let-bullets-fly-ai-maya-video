# 依赖说明 — 搬到自己电脑上要装什么

## 一句话

**只要 Maya 2024 或更新版本，别的什么都不用装。**

---

## 已实测的检查结果

在 Maya 里对这个 .mb 做了三项检查：

| 检查项 | 命令 | 结果 |
|---|---|---|
| 外部引用文件 | `cmds.file(q=True, reference=True)` | **空**，没有任何 reference |
| 贴图/图片节点 | `cmds.ls(type="file")` | **空**，一个贴图都没有 |
| 未知节点（缺插件） | `cmds.ls(type="unknown")` | **空**，没有插件依赖 |

文件大小 12.9 MB，全部内容都在这一个文件里。

---

## 具体说明

### 必须的

| 项 | 要求 | 说明 |
|---|---|---|
| Maya | **2024 或更新** | 文件是 Maya 2024 存的 mayaBinary。.mb **不向下兼容**——2023 及更早打不开，会直接报错 |

### 不需要的

| 项 | 为什么不需要 |
|---|---|
| 贴图文件 | 角色的材质是纯色 lambert（`color` + `ambientColor`），没有任何 `file` 节点 |
| 插件 | 场景里只用了 Maya 自带节点：poly 几何、lambert、skinCluster、blendShape、camera、ambientLight |
| 渲染器插件 | 出片用的是 Maya 自带的 playblast（视口连拍），不需要 Arnold / V-Ray |
| 字体 | 字幕是后期用 PIL 烧的，不在 Maya 里 |
| 原始 PMX 模型 | 角色已经转成 FBX 并导入进来了，源文件不用跟着走 |
| 项目文件夹结构 | 没有任何相对路径依赖，.mb 放哪都能开 |

### 如果哪天要重做角色才需要的（现在不用）

只有当你需要重新从 PMX 转换角色时，才需要这条链：

- Blender 4.x / 5.x
- Blender 插件 `mmd_tools`
- 原始 PMX 文件（在 `工作区域文件夹\models_raw\`，共 3 个角色）
- 转换脚本 `scripts\b1_export.py`

---

## 打开后的第一件事

1. `File > Open` 打开 `手工摆位_v2.mb`
2. 大纲视图里展开 `SCENE`，会看到 `CHARS` / `CAMERAS` / `GRP_SET` / `GRP_LIGHTS` / `HIDDEN_HELPERS` / `OBSERVATION_CAMERAS`
3. 想快速看整体，在视口面板切到 `OV_front1`（正面总览机位）
4. 移动人物只动 `CHR_Ma` / `CHR_Huang` / `CHR_Shiye` 这三个组

---

## 两个已知坑

**1. 相机名字带了个 `1`**

Maya 自动加的。实际叫 `S001_CAM1` … `S071_CAM1`，观察机位叫 `OV_front1` / `OV_left1` / `OV_right1` / `OV_top1`。不是笔误。

**2. 别改人物的 Y**

组的 Y 恒为 0，代表地面。改 Y 会让人离地或陷进椅子。只改 X / Z / rotateY。

**3. 网格不要挪**

`Ma_..._mesh` / `Huang_..._mesh` / `Shiye_..._mesh` 挂在 `CHARS` 下面，别动它们。它们带 ×100 缩放和蒙皮，改父级或改位置会让模型炸开。移动 `CHR_xx` 组的时候，网格会自动跟着走。
