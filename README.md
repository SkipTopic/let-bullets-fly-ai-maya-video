# 让子弹飞 · AI 控制 Maya 制作视频

这是一个完整的 Autodesk Maya 3D 动画实验工程：以《让子弹飞》鸿门宴片段为参考，由 AI 通过 Maya MCP 控制 Maya，完成模型转换、场景搭建、人物摆姿、71 镜相机、头部和手部动作、逐帧渲染、字幕与视频编码。

仓库 URL：

```text
https://github.com/SkipTopic/let-bullets-fly-ai-maya-video
```

> 本项目是技术实验和制作过程留档，不是电影素材发行，也不宣称达到“一比一电影复刻”。原片、角色模型和相关知识产权的权利归各自权利人。

## 仓库性质

- 完整工程留档：保留从早期失败版本到最终场景、渲染版本和成片的中间过程。
- 保留全部 `.mb` 场景版本、Python/MEL 脚本、日志、分镜、模型源文件、渲染帧和成片。

- 存在少量失败中间件、零字节图和无效执行日志；它们被保留用于复盘，不代表最终交付。

## 从视频到动画的工作方式

原始视频不是作为 Maya 背景图片播放，也不是逐帧描摹。处理方式是：

1. 用 `ffprobe` 读取原视频的分辨率、23.976fps、3512 帧和音轨信息。
2. 从参考画面和分镜表提取 71 个镜头的起始帧、结束帧、景别、人物动作、台词和运镜描述，形成 `shotlist.csv`。
3. 把每个镜头转换为 Maya 时间轴上的闭区间，例如 S001 = 1–56 帧，S071 结束于 3512 帧。
4. 根据分镜中的主体、视线、前后景和运镜设计相机 `eye / aim / focal / 起止关键帧`，写入 `shots_deepseek.json`。
5. 用 Maya 创建 `DS_S001_CAM1` 至 `DS_S071_CAM1` 等真实相机，并保存实际节点映射。
6. 对每一镜给人物设置头部看向谁、右手/左手做什么手势、何时保持，使用两段 IK 计算手腕目标，再把关节旋转烘焙成关键帧。
7. 按每镜帧范围调用 playblast 输出 PNG，检查帧数、黑帧和图像差异。
8. 按镜头时间顺序把序列帧编号为连续帧，使用 `24000/1001` 编码为 MP4，最后检查媒体参数和抽帧。

## 打开和复现

### 软件环境

- Autodesk Maya 2024（Windows 实测）
- Blender（仅重新转换 PMX/FBX 时需要）
- Python 3.10+（辅助脚本和 MCP）
- ffmpeg / ffprobe（编码和媒体验证）

### 打开最新场景

1. 安装并启动 Maya 2024。
2. 打开 `工作区域文件夹/scenes/DS_相机动作_v01.mb`。
3. 场景以 Maya 2024 保存；不要用更旧版本打开。
4. 在 Outliner 中查找 `DS_PRODUCTION_CAMERAS` 和各 `DS_Sxxx_CAM1` 相机。
5. 时间轴范围应为 1–3512；逐镜区间读取 `工作区域文件夹/shotlist.csv`。
6. 切换相机前确认当前可见 modelPanel，使用真实相机名，不要用假定名称。

### 脚本路径注意

项目脚本中的 `ROOT` 多数写死为原作者机器路径：

```text
C:\Users\admin\Desktop\MayaProject\让子弹飞分镜测试\工作区域文件夹
```

在其他电脑运行时：

1. 把脚本中的 `ROOT`、`SCENE`、`SEQ`、`PY`、`MAYA` 改成自己的路径。
2. 不要直接运行会覆盖原场景的“最终版”脚本。
3. 先复制场景到新版本，再测试单帧或单镜。
4. 部分早期脚本依赖特定 MCP、venv 或 Blender 路径，失败不代表当前场景损坏。

### 重渲单镜示例

```python
import maya.cmds as cmds

scene = r"C:\path\to\DS_相机动作_v01.mb"
cmds.file(scene, o=True, force=True)

panel = [p for p in cmds.getPanel(type="modelPanel") if cmds.control(p, q=True, visible=True)][0]
cam = "DS_S001_CAM1"
start, end = 1, 56
cmds.lookThru(panel, cam)
cmds.setFocus(panel)
cmds.currentTime(start)
cmds.refresh(force=True)
cmds.playblast(
    startTime=start,
    endTime=end,
    filename=r"C:\path\to\test\S001",
    format="image",
    sequenceTime=False,
    clearCache=True,
    viewer=False,
    showOrnaments=False,
    offScreen=True,
    percent=100,
    widthHeight=(960, 540),
    quality=85,
    compression="png",
)
```

不要再用 `frame=[start, end]`，它只表示两帧，不是连续区间。

### 遗留和已知问题

- 最新成片没有音轨。
- 人物并非原演员形象；角色外观、材质和场景为简化/风格化重建。
- 部分表演仍是按镜头模板生成，不是逐字逐帧的精演。
- 站起、坐下和复杂道具交互没有完全按原片实现。
- DS v03 历史和日志中存在黑帧、重复帧、硬编码修复计数等问题，不能当作完全可信的 QA。
- 16 个 `cmd/result_*.json` 不是合法 JSON，是截断或调试 stdout，保留仅作历史。
- 两个零字节 PNG 是损坏文件：`v7_final_depth.png`、`tmp/v7_final.png`。
- 不包含原视频；要完整复现参考对照，需要自行提供合法获得的原片。
