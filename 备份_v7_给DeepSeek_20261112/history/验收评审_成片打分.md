## 5. 2.5 小时修正路线（按性价比排序，共约 120 分钟）

### Step 1｜让 71 个镜头真的切起来（15 分钟，必做）
`p5_render2.py` 的循环体改成按镜取相机：

```python
for tag, f0, f1 in SHOTS:
    cam = "CAM_S%d" % tag
    if not cmds.objExists(cam):
        raise RuntimeError("missing " + cam)          # 不许静默降级
    cmds.modelEditor(mp, e=True, camera=cam)
    cmds.currentTime(f0)
    cmds.playblast(frame=list(range(f0, f1 + 1)), ...)
    print("shot %03d rendered via %s" % (tag, cam))
```

```bash

```
期望 ≈70 个切点。0 个就是又走老路了。

### Step 2｜让角色进画面（20 分钟，必做）
现状实测：三个 mesh 的 bbox 顶 y=69.3 / 73.5 / 78.5，桌面 75。抬 `translateY` 可整体刚性移动（我验证过：−46 → +12 时头顶 69 → 187.5，比例约 **2.04 倍**，因为 mesh 自带 scale=100）。

目标：bbox 高度 ≈175、头顶 ≈125（坐姿眼高）。用 bbox 闭环迭代两次，别算公式：

```python
def fit(mesh, target_h=175.0, target_top=125.0):
    for _ in range(3):
        bb = cmds.exactWorldBoundingBox(mesh)
        h = bb[4] - bb[1]
        if abs(h - target_h) > 8:
            s = cmds.getAttr(mesh + ".scaleY")
            cmds.setAttr(mesh + ".scaleY", s * target_h / h)
        bb = cmds.exactWorldBoundingBox(mesh)
        cmds.setAttr(mesh + ".translateY",
                     cmds.getAttr(mesh + ".translateY") + (target_top - bb[4]) * 0.45)
```
每调一次渲一张 854×480 静帧确认，看到"三个头在桌面上方"再往下走。

**保底**（超过 20 分钟没搞定就切）：删/隐藏 PMX，用 `胶囊躯干 + 球头 + 圆柱臂` 摆三个替身，高度 170、hip 对准椅面 44、头顶 122。丑但"有人"，比空桌强一个数量级。工程里的真角色和 skinCluster 保留不删，红线 #5 仍然成立。
